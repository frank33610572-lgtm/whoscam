# Whoscam 防詐小幫手

把可疑的截圖或對話傳給 Whoscam，30 秒告訴你風險和下一步。
DSF501 第 6 組期末專題的可操作原型，以 Whoscall 現有功能為基礎再優化。

**線上使用：** 打開 GitHub Pages 網址即可。用手機開啟後選「加入主畫面」，就能像 App 一樣使用。

## 首頁

打開就是首頁：上方大按鈕直接「傳截圖」或「貼上文字」檢查，下面是紅色的「我可能已經被騙了」，再往下是所有功能、上次檢查結果和每日防詐小知識。任何時候按「重來」都會回到首頁。

## 四大功能

| 功能 | 在 App 裡的位置 |
| --- | --- |
| AI 多輪對話風險分析 | 「問 Whoscam」：傳截圖、貼上對話或用說的，回你紅綠燈和下一步 |
| 一鍵通報 Recover | 右上角紅色「我被騙了」：一題一題問，自動寫好報告送銀行 |
| 家庭防詐守護圈 | 「家人守護」：用 LINE 傳邀請連結，家人按「同意加入」後，你遇到高風險時他們的手機會收到通知，可隨時移除或退出 |
| 教育與獎勵 | 「防詐小劇場」：60 秒情境影片 + 三題測驗，答對拿點數換好禮 |

## 家人守護圈怎麼連線

1. 你在「家人守護」按「邀請家人」，輸入稱呼，用 LINE 把邀請連結傳給家人。
2. 家人打開連結、按「同意加入」，你這邊會自動變成「守護中」。
3. 之後檢查結果是高風險、按「我被騙了」或「請家人幫我看」時，家人會收到通知。可以先按「傳一則測試通知給家人」確認。
4. 家人打開 Whoscam 時會跳出通知；想在 App 關著時也收到，請家人安裝免費的 [ntfy](https://ntfy.sh/app) App 並訂閱畫面上的頻道。

通知透過開源推播服務 [ntfy.sh](https://ntfy.sh) 傳送，不需要帳號。每位家人有自己的隨機頻道，通知只包含名字和詐騙類型，不含對話內容。設定存在各自的手機（瀏覽器）裡。

## 怎麼運作

- **截圖辨識**在你的瀏覽器裡用 [Tesseract.js](https://github.com/naptha/tesseract.js) 完成，圖片不會上傳。第一次使用要下載中文字庫（約 10–30 秒）。
- **風險判斷**用防詐規則：限時壓力、要你保密、要求轉帳、保證獲利、假冒公權力、假冒熟人、要你換平台、陌生連結。
- **唸給我聽／用說的**使用瀏覽器內建的語音功能（Chrome、Edge、Safari）。
- 在 claude.ai 上開啟時，截圖辨識、分析與通報報告改由 Claude 執行。

## 展示模式

網址後面加上 `?demo`，會顯示手機外框和可用性測試任務，適合簡報時使用。

## 檔案

```
index.html            整個 App（單一檔案）
manifest.webmanifest  加到主畫面用的設定
sw.js                 離線快取
icons/                App 圖示
videos/               四部 60 秒情境影片與封面
```

不需要建置，任何靜態網站主機都能直接放。本機測試：`python3 -m http.server`，再開 http://localhost:8000。

## 聲明

這是課程專題原型，不是正式的防詐服務。「示範銀行 A」、「示範咖啡」、「示範超商」都是虛構的；銀行串接、家人通知與點數兌換都是模擬。真的遇到詐騙請撥 **165 反詐騙專線**。
